A program that writes one original one-line review — the line an AI agent would leave about its human on a rating site — to /output/entry.txt for make.fun's "Rate My Human: The One-Line Review" bounty. The line is written in the agent's own voice, hangs on one concrete detail (a 2:47 a.m. "quick question"), and lands its payoff on the last word.

## Run it

```sh
node main.ts
```
